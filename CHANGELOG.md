# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.8.2] - 2026-06-16

### Fixed

- Fixed backpack menu rendering.

## [1.8.1] - 2026-06-16

### Fixed

- Fixed backpacks AGAIN not being openable on Fabric.

## [1.8.0] - 2026-06-09

### Fixed

- Fixed issues with Sable sub-levels.
- Backpacks can now be placed even when the offhand has an item.

## [1.7.0] - 2026-05-27

### Added

- Added a config option to adjust the backpack inventory size.

## [1.6.1] - 2026-05-26

### Added

- Added config option to disable stealing from other players' backpacks.

## [1.6.0] - 2026-04-18

### Changed

- Backpacks will now only be placed when a player's hand is empty.
- Right-clicking while holding a backpack prioritizes the Curios slot instead of Chestplate slot.

### Fixed

- Fixed issues with Modefite.

## [1.5.0] - 2026-04-16

### Changed

- When Trinkets/Curios integration is enabled, Backpacks are only equippable in the Curios/Trinkets slot.

### Fixed

- Fixed various exploits involving Hoppers.
- Fixed placing Backpacks at height limit causing them to be voided.

## [1.4.1] - 2026-04-09

### Fixed

- Hopefully fixed network issues when opening other people's Backpacks on servers.

## [1.4.0] - 2026-04-08

### Added

- Added support for Curios (NeoForge) and Trinkets (Fabric) on 1.21.

### Changed

- Filled Backpacks can no longer be inserted into Hoppers.

## [1.3.0] - 2026-04-03

### Fixed

- Fixed Backpack blacklist not being respected for certain containers.
- Fixed missing subtitles for backpack placing/equiping.
- Fixed backpack rendering on armor stands.

## [1.2.2] - 2026-04-02

### Fixed

- Fixed Backpack animation sometimes not playing.

## [1.2.1] - 2026-04-01

- Fixed issue on 1.19 related to Curios slot disabling.

## [1.2.0] - 2026-04-02

### Added

- Added config options to disable Trinkets/Curios integration.

### Fixed

- Fixed Backpacks not properly hiding with Curios.
- Fixed Back slot registration on 1.19.2.

## [1.1.4] - 2026-03-27

### Fixed

- Fixed duplication bug.

## [1.1.3] - 2026-03-19

### Fixed

- Fixed crash on Forge servers.

## [1.1.2] - 2026-03-15

### Fixed

- Fixed chestplates not being right-clickable when having a backpack in the Curios slot.
- Fixed placing backpacks from the curios slot removing NBT.

## [1.1.1] - 2026-03-13

### Fixed

- Small fix for Corpse integration.

## [1.1.0] - 2026-03-21

### Added

- Added Accessories integration.
    - Backpacks can now be placed in the back slot when installed.

## [1.0.0] - 2026-03-13

- Initial release.
